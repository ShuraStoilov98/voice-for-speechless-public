# Local Voice Samples

No recordings or voice script are distributed with this project. This directory ignores every file except this README.

Keep your consenting speaker's recordings private, preferably outside the checkout, and follow [voice setup](../../docs/PRIVACY_AND_VOICE_SETUP.md). The app plays speech; it does not record or upload voice samples.

An ignore rule is a convenience, not a way to erase previously committed recordings. Review staged files and full Git history before publishing any fork.
